## Analyse de risque de régression croisée
`RESULTAT_OPTIONS` est un tableau partagé (`resultatLabel()`, utilisé par `screen-book.js` pour les badges historique). L'extension est strictement additive (un 5e élément ajouté, aucun des 4 existants modifié) — `Array.find()` sur la valeur exacte garantit qu'aucun résultat existant (`but`/`arret`/`poteau`/`hors_cadre`) n'est affecté. Confirmé par le raisonnement du code (pas de mutation, pas de réordonnancement) ; les badges de ces 4 résultats avaient déjà été vérifiés visuellement corrects lors des E2E de STORY-07a/07b, avant cette extension.
