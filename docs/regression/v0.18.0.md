# Rapport de régression — v0.18.0 (STORY-15)

## Périmètre du changement

## Analyse de risque de régression croisée
Le risque principal identifié : la restructuration du markup (ajout d'un wrapper flex autour des boutons de sélection déjà existants) pourrait casser le tap de sélection lui-même. Vérifié : les actions de sélection (`select-gardien`, `select-equipe`, `select-tireur`) ont été exercées à plusieurs reprises pendant les tests de cette même story (restauration d'un gardien valide, navigation équipe→joueurs, préparation des scénarios de suppression) — toutes fonctionnelles, aucune régression observée sur le tap de sélection malgré la restructuration du markup.
